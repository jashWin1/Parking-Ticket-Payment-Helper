# Ticket Payment Program

This is a ticket payment program that I created using Python!

The program asks the user to:

1. Insert coins to pay for the ticket
2. Only use valid coins (1, 5, 10, or 25 cents)

The ticket costs 30 cents. The program keeps track of how much money the user has inserted and how many coins they have used. Once the user has inserted enough money, the program calculates their change and displays a payment summary.

If the user tries to insert an invalid coin, it gives them an error response saying "Invalid coin, please try again!"

Features include:

1. User input and interaction
2. Using a while loop
3. Tracking the total amount of money inserted
4. Tracking the number of coins inserted
5. Calculating change
6. Using a function to calculate change
7. Handling invalid inputs
8. Using if statements and continue and break

What I learnt:

1. How to create and use functions in Python
2. How to use a while loop to keep the program running until enough money is inserted
3. How to keep track of multiple variables at the same time
4. How to use continue when the user enters invalid input
5. How to use break to stop a loop when a condition is met
6. How to calculate and display change
7. How to create a payment summary using information collected during the program

About this project:

This is a simple ticket payment program I made in Python that simulates paying for a ticket using coins. When I was building this program, I learned more about functions, loops, variables, user input, and handling invalid inputs. This project helped me understand how different parts of a program can work together to simulate a real-world situation.
